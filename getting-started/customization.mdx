Change the prefix when it clashes with another bot, rename and recolour Zone like a member, and install its emoji pack so panels match the rest of your server.

## Name and prefix

Rename Zone in your server like any other member, give it a matching role colour, and change the prefix if the default clashes with other bots.

Changing the prefix needs Manage Server. Members can always see the current one.

## Emoji and icons

Zone can install its own emoji pack, which replaces the generic icons on panels and replies with matching ones. Servers without the pack fall back to standard characters, so nothing looks broken.

## Examples

### Pick a prefix nobody else uses

```text
/prefix value:?
```

Needs Manage Server. Members can always read the current prefix without changing it.

### Show the current one

```text
/prefix
```

Useful when someone asks why their old muscle memory no longer works.

### Avoid — A space is not a prefix

```text
/prefix value:" "
```

The prefix has to be something you can actually type before a command. Blank input is refused.

<Note>
  Panels posted before a change keep their old look. Repost them to pick up new emoji or naming.
</Note>
