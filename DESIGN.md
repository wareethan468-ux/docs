# Zone documentation design

Use Mintlify's native documentation layout, dark appearance, Zone logo and quiet blue accent.

Page changes use a 280 ms fade with at most 6 px of vertical movement. Shared links and controls use 220 ms color, fill and border transitions. Keep the sidebar stable when navigating. Respect reduced-motion preferences for transitions, entrance animations and scrolling.

Explain systems and setup workflows. Keep the command catalogue on the Zone website. Do not publish restricted owner-only guides.
