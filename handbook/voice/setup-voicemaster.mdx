Create personal voice rooms when members join a configured hub.

## Before you start

Choose a hub and room category.

Check channel management, voice movement and access permissions.

Manage Server opens shared setup; action-specific checks still apply.

## Open the setup flow

1. Open /setup in the server being configured.
2. Choose the category and **Voice Master** module.
3. Choose the relevant action and edit its settings. Required fields gate Run action.
4. Run the action and read its result. Reopen expired menus when needed.

## Configure and test

1. Select the hub/category and enable the module.
2. Optionally post the control board.
3. Join as a member and test room controls.
4. Leave and check empty-room cleanup.

## Verify your setup

- Occupied rooms are preserved.
- Members control their own tracked rooms.
- The creator and bot retain access needed by controls.

## Maintain the configuration

Keep destination channels and roles current. Replace deleted Discord objects through the matching setting. Disabling, resetting and deleting are different operations; inspect the selected action before applying it.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.

## Command syntax and examples

Templates show the expected argument structure, not literal values to send. These examples do not execute commands.

<AccordionGroup>

<Accordion title="/voicemaster set">

Change Voice Master settings

**Syntax**

```text
/voicemaster set <enabled> [hub] [category] [panel_channel]
```

**Example template**

```text
/voicemaster set enabled:<enabled>
```

Replace angle-bracket placeholders with real values; omit square-bracket options you do not need. Quote text containing spaces. Select the slash command in Discord and fill its named fields.

**Wrong**

```text
/voicemaster set
```

Missing `enabled`.

## Settings

### enabled

Enable or disable new rooms

### hub

Join-to-create channel

### category

Category for temporary voice rooms

### panel_channel

Channel for room controls

### channel

Text channel for the live controls
