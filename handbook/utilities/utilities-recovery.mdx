Message recovery groups the workflows below. Snipe deleted messages and reactions.

## What this module does

- Recover recent deleted or edited content
- Configure automatic reactions and view reaction history
- Clear all results for reactions, edits and messages
- View metadata for a message without copying its content
- Look up details about a supplied Discord invite
- Compare the permissions of two server roles
- List members who currently have a role
- Inspect bot permissions and server protection health

## Before you start

Choose the actual server, member, public URL or text.

Keep credentials and private data out of public chat.

Depending on the action, this module uses **Manage Messages, Manage Roles, Manage Server**. Stronger ownership and channel checks may apply.

## Setup and access

This module has no dedicated entry in shared setup. Use its supported Discord workflows. The command browser provides exact inputs; one-time configuration tools may still exist outside /setup.

## Everyday workflow

1. Review the accepted input.
2. Supply it and inspect the result.
3. Copy or download the artifact when one is produced.

## Check the result

- Missing records are reported instead of invented.
- Lookups show only accessible data.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
