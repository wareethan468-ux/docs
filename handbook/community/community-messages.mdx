Collect anonymous form submissions with optional category routing.

## What this module does

- Anonymous confessions with a word blacklist and categories
- Automatic replies for trigger words
- Make the bot repeat your text (no pings)
- Post a styled announcement card

## Before you start

Choose approved text channels.

Give Zone View Channel, Send Messages and Manage Webhooks; review prohibited words.

Depending on the action, this module uses **Manage Server, Manage Channels, Manage Messages**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Community**, then **Messages & responses**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Configure the main destination and post the panel.
2. Add category destinations if needed.
3. Submit a harmless test and inspect its anonymous post.
4. Test that a prohibited word refuses the entire submission.

## Check the result

- Each submission reaches its chosen category or the main channel.
- Blocked content is not partially posted.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
