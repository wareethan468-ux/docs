Send welcome messages on join and optional farewell messages on leave.

## What this module does

- Set up welcome and optional leave messages

## Before you start

Choose writable text channels.

Prepare text with the supported user, username, server and count placeholders.

Depending on the action, this module uses **Manage Server**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Community**, then **Welcome & greetings**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Save the welcome channel and text.
2. Enable farewell messages separately and choose their destination.
3. Preview substituted text before a real member event.
4. Keep bot greetings off unless wanted.

## Check the result

- Destinations and substituted values are correct.
- Previews and farewell messages do not ping.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
