Collect staff and promotion applications through a public panel and private review.

## Before you start

Choose a public panel destination and private review channel.

Choose reviewer roles and any roles granted after approval.

Manage Server opens shared setup; action-specific checks still apply.

## Open the setup flow

1. Open /setup in the server being configured.
2. Choose the category and **Staff applications** module.
3. Choose the relevant action and edit its settings. Required fields gate Run action.
4. Run the action and read its result. Reopen expired menus when needed.

## Configure and test

1. Save the requirements and post the panel.
2. Submit a test application and claim it as a reviewer.
3. Review its answers and record a decision with the requested reason.
4. Read the result before assuming that a role was granted or a DM was delivered.

## Verify your setup

- Application answers stay in the approved review area.
- Applicants cannot approve themselves; current reviewer access is required.

## Maintain the configuration

Keep destination channels and roles current. Replace deleted Discord objects through the matching setting. Disabling, resetting and deleting are different operations; inspect the selected action before applying it.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.

## Settings

### channel

Channel to post the applications panel in (default: here)

### staff_role

Role granted when a staff application is accepted

### promotion_role

Role granted when a promotion request is accepted

### notify_role

Role pinged when a new submission arrives

### review_role

Role allowed to claim and review applications

### review_channel

Private staff channel for application review cards

### requirements

What you are looking for, shown on the panel (editable later on the Customize page)
