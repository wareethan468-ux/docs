Profiles & information groups the workflows below. Look up members, roles, channels and server details.

## What this module does

- Show a user’s full-size profile picture
- Show a user’s profile banner with a full-size download button
- Show a profile picture
- Show member info
- View or erase observed member name history
- View server information privately — only you see the reply
- Show role information
- Show channel information

## Before you start

Agree on the audience before posting or changing shared records.

Depending on the action, this module uses **Manage Server**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Community**, then **Profiles & information**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Find the matching workflow in the command browser.
2. Supply the real member, record or channel.
3. Inspect the saved or posted result.

## Check the result

- Check visibility as a member.
- Use record identifiers when names are ambiguous.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
