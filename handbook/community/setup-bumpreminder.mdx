description: "Remind your server to bump it on DISBOARD"

---

Remind the server when a genuine successful bump becomes eligible again.

## Before you start

Choose the reminder channel and any intentional notification role.

Manage Server opens shared setup; action-specific checks still apply.

## Open the setup flow

1. Open /setup in the server being configured.
2. Choose the category and **Engagement** module.
3. Choose the relevant action and edit its settings. Required fields gate Run action.
4. Run the action and read its result. Reopen expired menus when needed.

## Configure and test

1. Save the reminder settings.
2. Check the response to a genuine supported-service bump.
3. Review the next reminder instead of fabricating a bump message.

## Verify your setup

- A normal member message is not a service confirmation.
- The destination remains writable.

## Maintain the configuration

Keep destination channels and roles current. Replace deleted Discord objects through the matching setting. Disabling, resetting and deleting are different operations; inspect the selected action before applying it.

## Settings

### channel

DISBOARD bump channel

### role

Role to ping, optional

### minutes

Reminder interval 60–360 (default 120)

Range: 60 to 360.
