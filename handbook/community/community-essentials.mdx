Everyday tools groups the workflows below. Help, setup, prefixes and everyday server tools.

## What this module does

- Browse Zone categories, modules and commands
- Configure a module
- Set your personal command prefix across all servers
- Invite Zone
- Post the Zone website and plans
- Go AFK — anyone who pings you gets your reason until you're back
- Find command aliases
- Show bot latency

## Before you start

Agree on the audience before posting or changing shared records.

Depending on the action, this module uses **Manage Server**. Stronger ownership and channel checks may apply.

## Setup and access

This module has no dedicated entry in shared setup. Use its supported Discord workflows. The command browser provides exact inputs; one-time configuration tools may still exist outside /setup.

## Everyday workflow

1. Find the matching workflow in the command browser.
2. Supply the real member, record or channel.
3. Inspect the saved or posted result.

## Check the result

- Check visibility as a member.
- Use record identifiers when names are ambiguous.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
