Engagement groups the workflows below. Reaction roles, highlighting, suggestions and scheduled posts.

## What this module does

- Configure and select notification ping roles
- Highlight popular server messages
- Submit or manage server suggestions
- Remind your server to bump it on DISBOARD
- Schedule recurring or one-time server messages
- Save and share named server snippets
- Schedule personal DM reminders
- Award and track member and staff reputation

## Before you start

Agree on the audience before posting or changing shared records.

Individual actions can still check channel access, ownership and service authorization.

## Setup and access

Open /setup, choose **Community**, then **Engagement**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Find the matching workflow in the command browser.
2. Supply the real member, record or channel.
3. Inspect the saved or posted result.

## Check the result

- Check visibility as a member.
- Use record identifiers when names are ambiguous.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
