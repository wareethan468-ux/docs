Collect staff and promotion applications through a public panel and private review.

## What this module does

- Post the staff application / promotion request panel

## Before you start

Choose a public panel destination and private review channel.

Choose reviewer roles and any roles granted after approval.

Depending on the action, this module uses **Manage Server**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Community**, then **Staff applications**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Save the requirements and post the panel.
2. Submit a test application and claim it as a reviewer.
3. Review its answers and record a decision with the requested reason.
4. Read the result before assuming that a role was granted or a DM was delivered.

## Check the result

- Application answers stay in the approved review area.
- Applicants cannot approve themselves; current reviewer access is required.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
