Create a configuration-file library with categories and review controls.

<Warning>Download anything you need before confirming a file deletion.</Warning>

## Before you start

Decide who may upload, review and download.

Choose panel destinations and approved notification roles.

Manage Server opens shared setup; action-specific checks still apply.

## Open the setup flow

1. Open /setup in the server being configured.
2. Choose the category and **Configs** module.
3. Choose the relevant action and edit its settings. Required fields gate Run action.
4. Run the action and read its result. Reopen expired menus when needed.

## Configure and test

1. Configure the library and post its panel.
2. Upload a test file with a clear name and description.
3. Review pending uploads before publishing.
4. Download an approved file as a member.

## Verify your setup

- Pending/rejected uploads stay protected.
- Removing a category preserves its files in the default category.

## Maintain the configuration

Keep destination channels and roles current. Replace deleted Discord objects through the matching setting. Disabling, resetting and deleting are different operations; inspect the selected action before applying it.

## Settings

### channel

Channel to post the panel in (default: here)

### ping_role

Role to notify for new configs

### manager_role

Role allowed to manage scripts and configs

### panel

Panel ID from the dashboard (default: default)
