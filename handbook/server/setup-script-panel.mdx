Inspect supplied Luau with static analysis and the limited sandbox workflow.

<Warning>Analysis does not prove that supplied code is safe to execute.</Warning>

## Before you start

Keep the original input and confirm permission to inspect it.

Manage Server opens shared setup; action-specific checks still apply.

## Open the setup flow

1. Open /setup in the server being configured.
2. Choose the category and **Script Dumper & Deobfuscation** module.
3. Choose the relevant action and edit its settings. Required fields gate Run action.
4. Run the action and read its result. Reopen expired menus when needed.

## Configure and test

1. Submit source or an attachment.
2. Read analysis status and recovery choices.
3. Download the archive and read its report.
4. Independently check recovered candidates before using them.

## Verify your setup

- Sandbox failure yields an explicit static-only result.
- Original source, candidates and event reports are distinguishable.

## Maintain the configuration

Keep destination channels and roles current. Replace deleted Discord objects through the matching setting. Disabling, resetting and deleting are different operations; inspect the selected action before applying it.
