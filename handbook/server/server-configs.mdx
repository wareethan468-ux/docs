Create a configuration-file library with categories and review controls.

<Warning>Download anything you need before confirming a file deletion.</Warning>

## What this module does

- Post a config panel
- Set up a config panel
- Add a script (category) to the config panel
- Remove a script (and all its configs) from the panel
- Add a config file to a selected panel and script
- Remove one config file from a script
- Change a script image
- Create a config category inside a script

## Before you start

Decide who may upload, review and download.

Choose panel destinations and approved notification roles.

Individual actions can still check channel access, ownership and service authorization.

## Setup and access

Open /setup, choose **Server & Content**, then **Configs**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Configure the library and post its panel.
2. Upload a test file with a clear name and description.
3. Review pending uploads before publishing.
4. Download an approved file as a member.

## Check the result

- Pending/rejected uploads stay protected.
- Removing a category preserves its files in the default category.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
