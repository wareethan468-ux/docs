Roblox lookups & scripts groups the workflows below. Find Roblox users, profiles, avatars, games, groups, scripts and executor status.

## What this module does

- Look up public Roblox users, avatars, games and groups
- Search public Roblox scripts across sources
- Post or edit Roblox script search panel
- View the script-search panel and active source settings
- Disable the public Roblox script-search panel
- View Roblox client versions and WEAO update tracking
- Post an auto-updating Roblox version status panel
- Check Roblox executor update status reported by WEAO

## Before you start

Confirm access and permission to change the content.

Depending on the action, this module uses **Manage Server**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Server & Content**, then **Roblox lookups & scripts**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Locate and inspect the correct resource.
2. Apply the supported operation.
3. Inspect the returned file or record before removing an original.

## Check the result

- Inspection does not automatically publish or approve content.
- Keep sources when an export or deletion fails.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
