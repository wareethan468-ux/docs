Street economy & earning groups the workflows below. Wallet, street card, jobs, payouts and quests.

## What this module does

- Street economy panel, toggle and log channel
- Full street command cheat sheet
- Show your cash, bank and net worth
- Street card with stats, rank and status
- Top street balances in this server
- Show your street rank
- Claim your street weekly payout
- Do a street job for cash

## Before you start

Choose a suitable channel and check balance, cooldown and consent.

Individual actions can still check channel access, ownership and service authorization.

## Setup and access

This module has no dedicated entry in shared setup. Use its supported Discord workflows. The command browser provides exact inputs; one-time configuration tools may still exist outside /setup.

## Everyday workflow

1. Review the activity inputs and limits.
2. Use its controls to finish the session.
3. Read the result before starting another round.

## Check the result

- A failed provider lookup does not complete an activity.
- Coin results use the saved server wallet and game rules.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
