Apply optional message transformations while retaining staff safeguards.

## Before you start

Use this where members understand the feature.

Check webhook and message permissions.

Manage Server opens shared setup; action-specific checks still apply.

## Open the setup flow

1. Open /setup in the server being configured.
2. Choose the category and **Fun message tools** module.
3. Choose the relevant action and edit its settings. Required fields gate Run action.
4. Run the action and read its result. Reopen expired menus when needed.

## Configure and test

1. Review protected members and staff exceptions.
2. Choose the member and strength.
3. Test the result and release the member when finished.

## Verify your setup

- Commands remain usable.
- A failed repost retains the original message.

## Maintain the configuration

Keep destination channels and roles current. Replace deleted Discord objects through the matching setting. Disabling, resetting and deleting are different operations; inspect the selected action before applying it.

## Settings

### user

Member to brainrot

### user

Member to release

### user

Member to protect

### user

Member to unprotect

### level

Brainrot level from 1 to 5

Range: 1 to 5.

### enabled

Start or stop random brainrotting

### chance

Ceiling percentage of messages that can be brainrotted

Range: 0 to 100.

### limit

How many messages an hour may be brainrotted at most

Range: 1 to 120.
