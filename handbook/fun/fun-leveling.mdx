Award server XP and grant configured roles at milestones.

## What this module does

- Configure and view server levels
- Give XP and levels to members, or set up level roles in one step
- Show a member level card
- Preview the level card without awarding XP

## Before you start

Choose XP and cooldown values that do not encourage spam.

Create reward roles below Zone and choose an optional announcement channel.

Depending on the action, this module uses **Manage Server**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Fun & Games**, then **Leveling**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Enable leveling and save the XP range/cooldown.
2. Map milestones to reward roles.
3. Send eligible messages and inspect rank/leaderboard views.
4. Check role access if XP increases without a reward.

## Check the result

- Bots, webhooks and handled commands do not earn ordinary message XP.
- Messages inside the cooldown do not add XP.
- Progress is per server; role grants obey hierarchy.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
