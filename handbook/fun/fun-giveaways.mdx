Run a timed giveaway with a prize, winners and eligibility rules.

## What this module does

- Run server giveaways

## Before you start

Confirm the prize, duration, audience and destination.

Depending on the action, this module uses **Manage Server**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Fun & Games**, then **Giveaways**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Save any defaults the server should reuse.
2. Create the event and inspect its posted end time.
3. Review participants through its controls.
4. End or reroll only when the server policy calls for it.

## Check the result

- The saved schedule and public message refer to the same event.
- Results reflect eligible participants.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
