Fun message tools groups the workflows below. Brainrot and uwu message pranks.

## What this module does

- Brainrot members or run roulette brainrotting
- Uwu-lock members or tune how much uwu their messages get

## Before you start

Choose a suitable channel and check balance, cooldown and consent.

Depending on the action, this module uses **Manage Messages**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Fun & Games**, then **Fun message tools**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Review the activity inputs and limits.
2. Use its controls to finish the session.
3. Read the result before starting another round.

## Check the result

- A failed provider lookup does not complete an activity.
- Coin results use the saved server wallet and game rules.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
