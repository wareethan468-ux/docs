---

title: "Troubleshooting"

description: "Resolve missing commands, stale panels and failed setup."

---

Read the exact result first. Missing input, channel access and provider failures need different fixes.

## Zone is quiet

1. Check Status and try a harmless information tool.
2. Verify the server prefix and command availability.
3. Check command-channel, disable and access rules.
4. Check View Channel and Send Messages in the actual destination.

## A role action fails

Check both staff and bot permissions, then compare role order. Managed roles and protected targets cannot be changed through ordinary grants.

## Panels and providers

Open a fresh setup session for stale controls. Check existing panels before reposting to avoid duplicates. External lookups and music can fail independently of the bot; retry known supported input and read the result.
