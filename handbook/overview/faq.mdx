Use module guides for feature-specific details.

## Where is the dashboard?

The dashboard is being retired. Configure and operate features through Discord setup and supported module tools.

## Why is a command missing from slash?

The prefix catalogue is broader. Select Both in the command browser and inspect availability.

## Does disabling erase settings?

Disabling commonly retains saved configuration. Delete and reset operations have different scopes; read the selected action before confirming it.

## Can Zone recover a whole server?

Message recovery depends on observed or cached events. Layout backups restore supported layout data, not deleted message history. Protection is not a substitute for backups.

## Who can use owner modules?

Trusted bot owners. Server administrator permission alone is insufficient.
