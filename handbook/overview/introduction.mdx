Start with the features your server needs, configure them in Discord, and test the member-facing workflow. This handbook covers every registered module and shared setup system.

## Choose your path

- New server: start with First setup and permissions.
- Existing server: choose a module and its setup walkthrough.
- Exact syntax: use the command browser, which owns the command catalogue.

## Using this handbook

Module guides explain purpose, access and everyday workflows. Setup pages describe prerequisites, settings and verification. Owner modules are labelled as restricted. The dashboard is being retired; Discord is the primary configuration surface.
