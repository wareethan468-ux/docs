Check current availability and inputs in the command browser. Replace its default prefix with your server prefix when needed.

## Find an action

Search by name, alias, description or argument. Slash, Prefix and Both filter availability. Expand a command and subcommand to inspect its workflow.

## Required and optional input

Required values must be supplied. Optional values can use a default, saved setting, current channel or current member. Hover or focus an argument chip for its meaning.

## Menus and privacy

Help and setup controls belong to their requester and can expire. Open a fresh menu when needed. Prefix responses are normally public; keep credentials and private staff material out of public messages.
