Configure one feature at a time. Test after reading the setup result.

## Prepare the server

1. Invite Zone and choose the correct server.
2. Create the member and staff roles your features need.
3. Place Zone above roles it must assign or moderate.
4. Give it access to the relevant text, voice and private staff channels.

## Configure a module

1. Open /setup in Discord with Manage Server access.
2. Choose a category, module and action.
3. Edit settings through the native pickers and forms.
4. Fill required settings, run the action and read the result. Optional values may reuse saved settings or defaults.
5. Test the workflow as a normal member.

## Roll out gradually

Start with logging and one member workflow. Review protection thresholds before enabling automatic actions. Tools without a shared setup entry can have their own prefix workflow.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
