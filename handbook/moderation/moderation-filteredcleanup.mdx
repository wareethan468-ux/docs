Targeted message cleanup groups the workflows below. Preview or remove recent messages by type with explicit confirmation.

## What this module does

- Delete recent messages with attachments
- Delete recent messages containing HTTP links
- Delete recent bot-authored messages
- Delete recent non-bot messages
- Delete messages mentioning users, roles or everyone
- Delete recent Discord invitation links
- Delete long messages dominated by uppercase text
- Delete messages containing custom Discord emojis

## Before you start

Confirm the affected target and your permission.

Check Zone role order.

Depending on the action, this module uses **Manage Messages**. Stronger ownership and channel checks may apply.

## Setup and access

This module has no dedicated entry in shared setup. Use its supported Discord workflows. The command browser provides exact inputs; one-time configuration tools may still exist outside /setup.

## Everyday workflow

1. Review current state.
2. Apply the action matching server policy.
3. Inspect the result and moderation history.

## Check the result

- Roles at or above Zone cannot be managed by it.
- Reports cannot reconstruct unknown historical events.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
