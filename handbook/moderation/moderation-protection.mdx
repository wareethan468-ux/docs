Rules & protection groups the workflows below. Honeypot, anti-nuke, anti-spam and anti-raid.

## What this module does

- View or manage the server rules
- Catch spam accounts that post in a trap channel
- Protect against destructive server actions
- Protect against floods, repeats and mass mentions
- Configure join-burst protection
- Filter words, links, spam and more from chat
- Show protection settings
- View live join-surge detection and emergency settings

## Before you start

Confirm the affected target and your permission.

Check Zone role order.

Depending on the action, this module uses **Manage Server, Administrator, Manage Messages**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Moderation**, then **Rules & protection**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Review current state.
2. Apply the action matching server policy.
3. Inspect the result and moderation history.

## Check the result

- Roles at or above Zone cannot be managed by it.
- Reports cannot reconstruct unknown historical events.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
