Member moderation groups the workflows below. Kick, ban, timeout and other member actions.

## What this module does

- Kick someone from the server
- Ban a member or user, including users outside the server
- Remove a member and delete recent messages without keeping the ban
- Inspect or correct a saved moderation case
- Manage private staff notes about members
- Temporarily ban a member
- Ban a user by ID, including users outside the server
- Ban listed members

## Before you start

Confirm the affected target and your permission.

Check Zone role order.

Depending on the action, this module uses **Kick Members, Ban Members, Moderate Members, Manage Roles, Manage Messages, Manage Channels, Manage Server, Manage Nicknames, Move Members**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Moderation**, then **Member moderation**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Review current state.
2. Apply the action matching server policy.
3. Inspect the result and moderation history.

## Check the result

- Roles at or above Zone cannot be managed by it.
- Reports cannot reconstruct unknown historical events.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
