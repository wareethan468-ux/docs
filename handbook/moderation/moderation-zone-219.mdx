Security incidents and archives groups the workflows below. Track incidents, inspect webhooks and archive or restore channels.

## What this module does

- Record a security incident without taking a punitive action
- Close a recorded security incident with a resolution note
- Send recorded security incidents to staff privately as CSV
- List webhook names and owners without exposing webhook URLs
- Archive a text channel with its current settings preserved
- Restore channel settings saved before archiving
- Compare effective channel permissions for two members
- Review channels without recent visible messages

## Before you start

Confirm the affected target and your permission.

Check Zone role order.

Depending on the action, this module uses **Manage Server, Manage Webhooks, Manage Channels**. Stronger ownership and channel checks may apply.

## Setup and access

This module has no dedicated entry in shared setup. Use its supported Discord workflows. The command browser provides exact inputs; one-time configuration tools may still exist outside /setup.

## Everyday workflow

1. Review current state.
2. Apply the action matching server policy.
3. Inspect the result and moderation history.

## Check the result

- Roles at or above Zone cannot be managed by it.
- Reports cannot reconstruct unknown historical events.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
