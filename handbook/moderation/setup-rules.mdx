Publish server rules and keep their saved wording current.

## Before you start

Prepare final text and choose a public destination.

Manage Server opens shared setup; action-specific checks still apply.

## Open the setup flow

1. Open /setup in the server being configured.
2. Choose the category and **Rules & protection** module.
3. Choose the relevant action and edit its settings. Required fields gate Run action.
4. Run the action and read its result. Reopen expired menus when needed.

## Configure and test

1. Save the rules text and heading.
2. Review the result as a member.
3. Update it when the actual server policy changes.

## Verify your setup

- Members can read the destination.
- Staff apply the same policy that the panel displays.

## Maintain the configuration

Keep destination channels and roles current. Replace deleted Discord objects through the matching setting. Disabling, resetting and deleting are different operations; inspect the selected action before applying it.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.

## Command syntax and examples

Templates show the expected argument structure, not literal values to send. These examples do not execute commands.

<AccordionGroup>

<Accordion title="!rules show">

Read the saved server rules

**Syntax**

```text
!rules show
```

**Example template**

```text
!rules show
```

Replace angle-bracket placeholders with real values; omit square-bracket options you do not need. Quote text containing spaces. Use your server prefix if it differs from !.

**Wrong**

```text
rules show
```

Missing the ! command prefix.

</Accordion>

<Accordion title="!rules set">

Save server rules (Manage Server required)

**Syntax**

```text
!rules set <text> [title]
```

**Example template**

```text
!rules set text:<text>
```

Replace angle-bracket placeholders with real values; omit square-bracket options you do not need. Quote text containing spaces. Use your server prefix if it differs from !.

**Wrong**

```text
!rules set
```

Missing `text`.

</Accordion>

## Settings

### text

Rules text; use actual newlines or \n

### title

Panel title

### channel

Where to post (default: here)
