Route selected server events to independent staff destinations.

## Before you start

Choose staff channels and event types.

Decide whether message-content logging is appropriate.

Manage Server opens shared setup; action-specific checks still apply.

## Open the setup flow

1. Open /setup in the server being configured.
2. Choose the category and **Logs & appeals** module.
3. Choose the relevant action and edit its settings. Required fields gate Run action.
4. Run the action and read its result. Reopen expired menus when needed.

## Configure and test

1. Select event types and destinations.
2. Run the supported delivery test.
3. Review each type; bulk changes affect selected types.
4. Disable unwanted types while retaining saved destinations.

## Verify your setup

- Tests arrive in the intended channel.
- Private content is not exposed to an inappropriate audience.

## Maintain the configuration

Keep destination channels and roles current. Replace deleted Discord objects through the matching setting. Disabling, resetting and deleting are different operations; inspect the selected action before applying it.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.

## Command syntax and examples

Templates show the expected argument structure, not literal values to send. These examples do not execute commands.

<AccordionGroup>

<Accordion title="/logs set">

Enable or disable selected log types

**Syntax**

```text
/logs set <enabled> <types> [channel] [message_content]
```

**Example template**

```text
/logs set enabled:<enabled> types:<types>
```

Replace angle-bracket placeholders with real values; omit square-bracket options you do not need. Quote text containing spaces. Select the slash command in Discord and fill its named fields.

**Wrong**

```text
/logs set
```

Missing `enabled`, `types`.

## Settings

### enabled

Enable or disable these log types

### types

Comma-separated types, or all

### channel

Log channel; blank keeps saved channels

### message_content

Include message text in edit/delete logs (default off)

### type

Log type

Choices: Commands & dashboard, Voice, Verification, Giveaways, Messages, Members, Roles, Channels, Moderation, Tickets, Configs & scripts, Staff applications, Protection, Server.
