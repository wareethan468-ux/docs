Channel & thread maintenance groups the workflows below. Manage channels, voice limits, message pins and threads.

## What this module does

- Update a text channel topic
- Enable or disable a channel NSFW flag
- Move a channel to a selected category
- Sync a channel permission overwrites with its category
- Set voice channel bitrate in kbps
- Update the voice channel member limit
- Duplicate a channel with its current settings
- Move a channel to a numeric position

## Before you start

Confirm the affected target and your permission.

Check Zone role order.

Depending on the action, this module uses **Manage Channels, Manage Roles, Manage Messages**. Stronger ownership and channel checks may apply.

## Setup and access

This module has no dedicated entry in shared setup. Use its supported Discord workflows. The command browser provides exact inputs; one-time configuration tools may still exist outside /setup.

## Everyday workflow

1. Review current state.
2. Apply the action matching server policy.
3. Inspect the result and moderation history.

## Check the result

- Roles at or above Zone cannot be managed by it.
- Reports cannot reconstruct unknown historical events.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
