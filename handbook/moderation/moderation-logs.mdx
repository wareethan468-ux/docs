Logs & appeals groups the workflows below. Moderation logs, stats and appeals.

## What this module does

- Show member moderation history
- Show recent server audit entries and saved bot actions
- Show moderation action totals
- Manage appeals for this server
- Configure log types and channels
- Send all log types to a channel
- Choose the support staff role

## Before you start

Confirm the affected target and your permission.

Check Zone role order.

Depending on the action, this module uses **Moderate Members, View Audit Log, Manage Server**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Moderation**, then **Logs & appeals**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Review current state.
2. Apply the action matching server policy.
3. Inspect the result and moderation history.

## Check the result

- Roles at or above Zone cannot be managed by it.
- Reports cannot reconstruct unknown historical events.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
