Staff audit reports groups the workflows below. Review permissions, roles, members, channels, bots and webhooks.

## What this module does

- Summarize roles, permissions and assignment coverage
- Find roles with no cached members
- Audit roles with high-risk permissions
- List cached members assigned to a role
- List roles assigned to cached bot accounts
- Show member counts by server role
- Summarize channel types and settings
- Find channels not synced with their category

## Before you start

Confirm the affected target and your permission.

Check Zone role order.

Depending on the action, this module uses **Manage Roles, Administrator, Manage Channels, Manage Webhooks, Manage Server, Moderate Members**. Stronger ownership and channel checks may apply.

## Setup and access

This module has no dedicated entry in shared setup. Use its supported Discord workflows. The command browser provides exact inputs; one-time configuration tools may still exist outside /setup.

## Everyday workflow

1. Review current state.
2. Apply the action matching server policy.
3. Inspect the result and moderation history.

## Check the result

- Roles at or above Zone cannot be managed by it.
- Reports cannot reconstruct unknown historical events.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.
