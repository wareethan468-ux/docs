Channel controls groups the workflows below. Slowmode, locks, sticky notes and channel tools.

## What this module does

- Keep a message pinned at the bottom of a channel
- Create a text or voice channel
- Delete a channel after confirmation
- Set file and embed permissions in a channel
- Set this channel's slowmode
- Lock a text channel
- Restore a text channel lock
- Hide a channel from a member or role

## Before you start

Confirm the affected target and your permission.

Check Zone role order.

Depending on the action, this module uses **Manage Server, Manage Channels, Manage Roles**. Stronger ownership and channel checks may apply.

## Setup and access

Open /setup, choose **Moderation**, then **Channel controls**. Choose an action, fill required settings and run it. Use the linked setup guides for each system.

## Everyday workflow

1. Review current state.
2. Apply the action matching server policy.
3. Inspect the result and moderation history.

## Check the result

- Roles at or above Zone cannot be managed by it.
- Reports cannot reconstruct unknown historical events.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
