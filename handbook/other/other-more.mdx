More commands groups the workflows below. Uncategorised commands.

## What this module does

- Unicode details for a single character
- Generate a random hex color
- Time difference between two Discord snowflakes
- Most used Zone commands in this server
- Evaluate arithmetic safely; arbitrary code is disabled
- Convert an attached audio or video file to MP3
- Transcribe an attached audio or video file
- Compress an uploaded image to JPEG

## Before you start

Review permission and target first.

Depending on the action, this module uses **Manage Server**. Stronger ownership and channel checks may apply.

## Setup and access

This module has no dedicated entry in shared setup. Use its supported Discord workflows. The command browser provides exact inputs; one-time configuration tools may still exist outside /setup.

## Everyday workflow

1. Choose the matching tool in the browser.
2. Follow its inputs and inspect the response.

## Check the result

- Confirm the result using its record or artifact.

## Troubleshooting

Check the target, destination and saved settings before repeating a mutation. Use the current browser inputs and the Troubleshooting guide for access, hierarchy and provider issues.

## Open shared setup

**Syntax and example**

```text
/setup
```

Choose the module using the menu; module names are not arguments to this command.

**Wrong**

```text
setup
```

Missing the slash. Select `/setup` from Discord’s command picker.
