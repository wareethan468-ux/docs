Upload, download and organize config files for scripts.

**Family:** Server

## Using it

The [command browser](https://zone-bot.freebuff.page/#/commands) lists every current command, argument and permission for Config manager. It stays current with Zone updates, so this page describes the system instead of copying the command list.

## Configuration

Use `/setup` in Discord for configurable modules, or open the [dashboard](https://zone-bot.freebuff.page/#/dashboard) to review what is enabled. The command browser lists any one-off actions.
