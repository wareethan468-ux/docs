## Using it

The [command browser](https://zone-bot.freebuff.page/#/commands) lists every current command, argument and permission for Scheduled messages. It stays current with Zone updates, so this page describes the system instead of copying the command list.

Use `/setup` in Discord for configurable modules, or open the [dashboard](https://zone-bot.freebuff.page/#/dashboard) to review what is enabled. The command browser lists any one-off actions.
